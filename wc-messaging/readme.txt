== Important: Dedicated phone number required ==

The standard setup requires a dedicated phone number registered with the WhatsApp Business Platform and not connected to the WhatsApp mobile apps. Calls and SMS may still work. Number coexistence depends on Meta eligibility and integration support.
Read [WhatsApp Cloud API phone number requirements](https://developers.facebook.com/docs/whatsapp/cloud-api/phone-numbers/).
Want to test Notiqoo without using your production WhatsApp number? Try a [virtual phone number for WhatsApp Business](https://notiqoo.com/virtual-phone-number-for-whatsapp/).

== Installation ==

* Install and activate WooCommerce if it is not already installed.
* Navigate to Plugins → Add New Plugin in your WordPress dashboard.
* Search for Notiqoo and install the plugin, or upload the plugin ZIP file.
* Activate Notiqoo.
* Open the Notiqoo settings in your WordPress dashboard.
* Configure your WhatsApp Business Platform credentials and phone number details.
* Set up the required message templates and notification options.
* Enable the notification events you want to use.
* Place a test order and verify that the expected WhatsApp notification is delivered.

You may need to configure a Meta app and complete the required WhatsApp Business Platform setup before sending messages.
For setup instructions, visit the [Notiqoo documentation](https://notiqoo.com/docs/notiqoo-pro/).

== Frequently Asked Questions ==

= Is Notiqoo free? =

Yes. Notiqoo offers a free version with essential WooCommerce WhatsApp notifications. Notiqoo Pro adds advanced features for customer support, marketing, authentication, and automation.

= Does Notiqoo use the official WhatsApp API? =

Yes. Notiqoo integrates with the official WhatsApp Business Platform using the WhatsApp Cloud API. You configure your own Meta and WhatsApp Business Platform assets.

= Do I need a dedicated phone number to use Notiqoo? =

Yes. The standard setup requires a number registered with the WhatsApp Business Platform. Eligibility for existing numbers depends on Meta's requirements and integration support.
Read [WhatsApp Cloud API phone number requirements](https://developers.facebook.com/docs/whatsapp/cloud-api/phone-numbers/)

= Can I send WooCommerce order notifications for free? =

Yes. The free version supports WooCommerce order notifications through your configured WhatsApp integration. Meta's messaging policies and any applicable charges still apply.

= Can customers reply to my WhatsApp notifications? =

Two-way customer messaging is available with Notiqoo Pro. Customers can reply through WhatsApp, and supported incoming messages can be managed from your WordPress dashboard.

= Can I automate abandoned cart recovery? =

Yes. Notiqoo supports abandoned cart messaging workflows. Notiqoo Pro extends these capabilities with configurable recovery reminders and supported coupon workflows.
Learn more [WooCommerce abandoned cart recovery](https://notiqoo.com/woocommerce-abandoned-cart-recovery/)

= Can customers log in using WhatsApp? =

Yes. Notiqoo Pro supports WhatsApp OTP login and signup for WooCommerce customers.Learn [WhatsApp Login and Signup for WooCommerce](https://notiqoo.com/whatsapp-login-signup-woocommerce/)

= Can I verify Cash on Delivery orders using WhatsApp? =

Yes. Notiqoo Pro supports COD order verification using WhatsApp OTP.Learn more [WooCommerce COD order verification](https://notiqoo.com/cod-order-verification-woocommerce/)

= Can I send WhatsApp broadcast campaigns? =

Yes. Notiqoo Pro supports broadcasts using approved WhatsApp templates, with audience selection and scheduling options.Learn [WhatsApp broadcast messaging for WooCommerce](https://notiqoo.com/whatsapp-broadcasting-woocommerce/)

= Can I collect product reviews through WhatsApp? =

Yes. Notiqoo Pro supports WhatsApp review requests and customer submissions, including supported review photos and videos.[Explore Notiqoo features](https://notiqoo.com/features/)

= Can I receive contact form submissions on WhatsApp? =

Yes. Notiqoo Pro supports WhatsApp notifications for submissions from compatible WordPress form plugins. Read [WhatsApp form integration for WooCommerce](https://notiqoo.com/docs/notiqoo-pro/setting-page/contact-form-submissions-to-whatsapp/)

= Where can I get support? =

Free-version users can request community support through the [Notiqoo WordPress.org support forum](https://wordpress.org/support/plugin/wc-messaging/).
For documentation, premium support, and information about Notiqoo Pro, visit [notiqoo.com](https://notiqoo.com/).
